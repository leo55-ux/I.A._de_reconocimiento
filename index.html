Ilustración del funcionamiento

¿En qué consiste el proyecto?

Es una página web que detecta objetos como puertas, billetes, personas y balones usando Machine Learning, y le dice al usuario qué objeto es.

¿Qué problema busca resolver?

Clasificar o detectar objetos.

¿Cuál es su objetivo?

Clasificar y detectar todo tipo de objetos.

¿Cómo funciona?

Por medio de la cámara de un dispositivo móvil y un programa de Machine Learning, escanea el objeto para saber qué es y lo dice tanto con texto como pronunciando su nombre.

¿Funcionó como esperaban?

Funcionó correctamente, con una dificultad mínima: en ocasiones confundía objetos.

¿Qué dificultades tuvieron?

Algunos billetes se reconocieron como otra denominación. Por ejemplo, el de 50 lo reconoció como de 200.

¿Cómo solucionaron los problemas?

Se mejoró el modelo de Machine Learning.

Propuestas de mejora

  • Clasificar los colores de ciertos objetos (no personas).
  • Tener un catálogo de objetos más amplio.
  • Convertir la página web del modelo en una aplicación.

Conclusión

Durante el desarrollo de este proyecto aprendimos a integrar tecnologías de desarrollo web con herramientas de inteligencia artificial y reconocimiento de imágenes. Aplicamos conocimientos sólidos en programación, utilizando HTML, CSS y JavaScript para diseñar una interfaz intuitiva, además de integrar la lógica y las librerías necesarias para que la plataforma pudiera procesar y analizar una fotografía en tiempo real. Esto nos permitió comprender de forma práctica cómo transformar conceptos teóricos de la informática en una aplicación funcional y accesible para cualquier usuario.

La importancia de esta página web radica en su capacidad para agilizar la identificación de elementos y ofrecer soluciones prácticas en la vida diaria. Al automatizar el reconocimiento de objetos, la herramienta puede aplicarse en múltiples áreas, desde fines educativos hasta mejorar la accesibilidad digital o clasificar información visual con rapidez. Este proyecto demuestra cómo la tecnología actual puede ser aprovechada para resolver problemas cotidianos de manera eficiente e interactiva.
